# Notice

Hermes Family Doctor is an engineering safety core for local medical-information coordination. It is not a medical device, a physician, a diagnosis service, or a substitute for emergency care.

The base package contains no patient records, credentials, private runtime state, downloaded medical datasets, or bundled drug-interaction database.

The optional SQLite interaction-provider interface accepts an owner-supplied database. DDInter data is not distributed here. If you prepare a DDInter-derived database, review DDInter's current terms and attribution requirements before use; the upstream dataset has non-commercial/share-alike constraints that are not granted by this repository's MIT license.

Medical source content is fetched from its original public provider and remains subject to that provider's terms. The source catalog records purpose and limitations; a successful request is not clinical validation.
