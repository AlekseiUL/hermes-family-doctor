# Laboratory review

1. Require the exact test name, value, unit, laboratory reference interval and date. Ask for fasting/time-of-day, symptoms, relevant medicines and prior values only when they affect interpretation.
2. Compare with the laboratory's own interval and the patient's trend. Do not normalize units by guesswork and do not infer a diagnosis from one outlier.
3. Separate analytic variation, common non-diagnostic explanations, clinically important possibilities and what cannot be concluded.
4. State the practical next step, suggested timing for clinician review and urgent return precautions when applicable.
5. The current Telegram adapter has no verified document-ingestion surface; never claim to have read an attachment that was not provided through a reviewed tool.
